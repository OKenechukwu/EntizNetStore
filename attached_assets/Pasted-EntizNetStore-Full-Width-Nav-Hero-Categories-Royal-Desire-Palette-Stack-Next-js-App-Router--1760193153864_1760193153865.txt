0) Brand Palette — Royal Desire (Option A) APPLY GLOBALLY (all pages)

Define CSS variables and wire Tailwind to semantic tokens. Use these names; apply everywhere.

globals.css

:root {
  --brand-primary: #7A00D1;   /* Royal Purple */
  --brand-secondary: #D1B000; /* Luxury Gold */
  --background: #0B0A0D;      /* Velvet Black */
  --foreground: #F4F3F6;      /* Off-white text */
  --muted: #1A1720;
  --card: #121017;
  --border: rgba(255,255,255,0.12);
}


tailwind.config.ts

theme: {
  extend: {
    colors: {
      background: "var(--background)",
      foreground: "var(--foreground)",
      border: "var(--border)",
      brand: {
        primary: "var(--brand-primary)",
        secondary: "var(--brand-secondary)",
      },
      card: "var(--card)",
      muted: "var(--muted)",
    },
  },
}


Rule: Replace any hardcoded bg-white, text-black, border-gray-200 with these semantic tokens (bg-background text-foreground border etc.). Hover accents should use brand.secondary with low opacity.

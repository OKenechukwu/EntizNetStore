## 🚨 CRITICAL BUGS (FIX FIRST – PRIORITY 0)

BUG 1: Currency Switching

* Currency changes, but ALL prices display as 0.00
* TRACE full data flow:
  DB → API → state → UI → formatting
* Fix:

  * missing base price values
  * broken conversion logic
  * wrong field mapping
  * NaN/undefined fallback to 0
  * async timing issues
  * SSR/CSR mismatch
* Ensure:

  * prices NEVER silently become 0 unless truly zero
  * switching currency does NOT mutate base values
  * values persist after refresh and navigation

BUG 2: Translation / Localization

* Some parts translate, many do not
* Audit ALL UI text:
  nav, buttons, forms, modals, errors, toasts, dashboards, checkout
* Fix:

  * hardcoded strings
  * missing translation keys
  * components outside provider
  * hydration mismatch
* Ensure:

  * 100% translation coverage
  * language persists after refresh/login
  * fallback language works correctly

BUG 3: Cart / Save / Persistence

* Cart not saving or inconsistent
* Fix:

  * add/remove/update quantity
  * persistence after refresh
  * guest → user merge
  * totals consistency
* Ensure:

  * cart survives navigation + login
  * no duplicate or lost items
  * totals always correct

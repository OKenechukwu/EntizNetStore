1.3 Replacement rules

At the top of each file that renders a price:

import Price from "@/components/ui/Price";


Replace hardcoded price nodes:

// BEFORE
<div className="font-extrabold">$67.24</div>

// AFTER
<div className="font-extrabold">
  <Price amount={67.24} />
</div>


Replace dynamic strings ("$99" or priceLabel: "$..."):

// BEFORE
<div className="font-extrabold">{product.priceLabel}</div>

// AFTER
<div className="font-extrabold">
  <Price amount={Number(product.price ?? product.priceLabel)} />
</div>


If the value includes currency symbols (e.g., "€99" / "USD 99"), strip non-digits:

const clean = Number(String(product.priceLabel ?? product.price).replace(/[^\d.]/g, ""));
<Price amount={clean} />


Prefer normalizing mock data once:

// data/mock*.ts
price: Number(String(priceLabel).replace(/[^\d.]/g, "")),
// then:
<Price amount={item.price} />


Cart math must remain numeric:

// BEFORE
const subtotal = `$${(qty * unitPrice).toFixed(2)}`;

// AFTER
const subtotal = qty * unitPrice;
<Price amount={subtotal} className="font-semibold" />
